# Diamond Baseball

A browser-based baseball game prototype focused on polished menus and a complete Quick Match flow.

## Run

Open `index.html` directly, or serve the repository with:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Main menu with five visually distinct game modes
- Quick Match team selection
- Game settings
- Interactive pitching and batting prototype
- Box score and important-plays summary
- Responsive desktop presentation
